Contenitori semantici: sono contenitori che a livello di caratterisriche sono identici ai div. Cio' che cambia è il loro significato.

Ci permettono di evitare la div-soup, questo a livello SEO ci aiuta molto in modo da far arrivare tra i primi risultati nel motore di ricerca

nav: Navbar - barra di navigazione
header: intestazione
mamin: tag contenitore del contenuto principale
footer: piè di pagina
section: sezione
article: contiene un blocco specifico di informazioni appartenenti ad un unica sezione
aside: contenitore di informazioni esterne ma pertinenti ex. banner pubblicitari


FORM: sono dei tag speciali che hanno lo scopo di raccogliere i dati

Attributi di form: "action" per dire come deve dire le cose al backend, "method" per dire cosa deve fare il form

1. Inserimento dei dati -> input (attributi utili "placeholder", "id" univoco e serve per identificare l'input), text area(attributi utili "cols", "rows" per satabilirne le dimensioni)
TIPI DI INPUT: text, email, password
2. Submit -> button
3. Etichette -> label
